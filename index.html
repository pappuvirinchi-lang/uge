ENGINE FOUNDATION

High-Performance Native Pipeline

UGE strips away layers of runtime baggage to give developers direct hardware control and crystal-clear memory predictability.

Native C++ Engine Core

Zero garbage collection pauses, low-level memory control, and minimal binary overhead. Built from scratch with clean modular CMake targets.

  • Deterministic tick execution
  • High-throughput multi-core architecture
  • Clean separation of Core, Engine, and Editor modules

Dockable Studio Editor

Modern studio interface featuring seamless panel docking, real-time scene hierarchy, transform gizmos, asset browsers, and instant inspector feedback.

  • Fully custom multi-docking layouts
  • Real-time entity transform inspection
  • Integrated logger, console, and performance profiler

Visual Blueprint Node Graph

Build game logic, math operations, and state flow using intuitive node graphs. Features type-safe pin connections, searchable node palette, and instant compilation.

  • Live typed pin validation (Exec, Float, Vector, Entity)
  • Instant keyboard typing node palette search
  • Real-time visual node execution & debugging

Modern 3D Render Hardware Interface (RHI)

Abstracted graphics backend ready for HLSL/GLSL shaders, custom mesh batching, environment lighting, and high-frequency camera matrices.

  • Dynamic vertex/index buffer management
  • Custom shader reflection & pipeline states
  • Optimized editor camera with smooth flight control

ENGINE ARCHITECTURE

Technical Specifications

Designed with clean software engineering patterns for maximum readability and speed.

01

Core & Build System

Standardized on Modern C++20 with CMake build pipelines. Fast compilation, zero non-essential external bloat, and automated developer certificate tooling.

CMake 3.20+ • C++20 • MSVC/Clang
02

Graphics Hardware Interface (RHI)

Clean rendering abstractions with support for dynamic HLSL shaders, standard 3D pipeline states, vertex/index staging, and multi-mesh rendering.

Direct3D / Vulkan • HLSL Shaders
03

Visual Blueprint Architecture

Integrated node execution VM with fast data-pin serialization, type deduction, custom pin drawing, and searchable node discovery for fast logic prototyping.

GraphVM • Pin-Typing • Real-time Introspection
04

Asset & Scene Management

Hierarchical entity transform systems, integrated editor camera raycasting, and fast asset streaming for textures and standard 3D mesh formats.

Transform Hierarchy • Texture & Mesh IO
